# INfragmentado
*INfragmentado* é um jogo narrativo curto criado para a Game Jam, cujo tema é *“Apenas Um”*.

O jogador controla uma silhueta humana completamente preta, sem rosto e sem nome. No início, ela parece vazia e não sabe exatamente quem é. Durante a jornada, encontra quatro figuras que representam diferentes emoções:

- 🟡 Alegria
- 🔵 Tristeza
- 🔴 Raiva
- 🟣 Medo

Cada emoção conhece apenas uma parte da pessoa. Nenhuma delas conhece a pessoa por completo.

O objetivo não é derrotar ou eliminar as emoções. O jogador deve *compreendê-las e reconhecer sua função*.

Cada emoção ensina uma habilidade diferente:

> 🟡 Alegria → *ILUMINAR / REVELAR*  
> 🔵 Tristeza → *PARAR / OBSERVAR*  
> 🔴 Raiva → *ROMPER / ENFRENTAR*  
> 🟣 Medo → *PERCEBER / ANTECIPAR*

Depois de compreender cada emoção, ela não desaparece. Um pequeno fragmento luminoso de sua cor passa a acompanhar a silhueta.

No final, os quatro fragmentos se revelam como partes de uma mesma pessoa.
O conceito visual principal é o *prisma de Newton*:

> Uma luz branca pode ser separada em várias cores, mas as cores continuam sendo manifestações da mesma luz.

Isso representa a ideia central do jogo:

> *Uma pessoa pode possuir diferentes emoções sem deixar de ser uma só pessoa.*
